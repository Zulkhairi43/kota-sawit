Kota Sawit adalah game open-world 2D top-down di kota tropis fiktif: jalan kaki atau mengemudi, curi mobil, kabur dari polisi, dan selesaikan empat misi cerita — antar paket, kejar target, kabur dari kejaran, antar penumpang. Ada lalu lintas dan pejalan kaki yang hidup, sistem wanted 0–5 bintang, combat jalan kaki, HUD dengan minimap live, save di localStorage, dan suara synth WebAudio. Semua kota, karakter, dan cerita orisinal, dibangun dengan JavaScript vanilla tanpa library eksternal.

## Run it

```sh
node serve.ts
```

Lalu buka http://localhost:8080 di desktop Chrome. Atau sajikan folder `game/` dengan server statis apa pun dan buka `game/index.html`.

## Cara main

- **WASD / panah** — jalan kaki dan mengemudi (Shift = lari)
- **E** — masuk / keluar mobil (mencuri mobil menaikkan wanted)
- **F** — pukul (jalan kaki), **G / klik** — tembak (butuh pistol + amunisi)
- **Spasi** — rem tangan saat mengemudi, **P / Esc** — jeda, **R** — main lagi setelah game over
- Cari marker kuning di peta/minimap untuk memulai misi. Wanted turun kalau lama tidak berbuat jahat dan tidak terlihat polisi.
